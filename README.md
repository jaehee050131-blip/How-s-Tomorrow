# Weather Dragon

A weather-based message sharing web application.

## Main Features
- Select a city in South Korea.
- Create a shareable message link.
- Display a dragon character based on tomorrow's weather.

## Tech Stack
- Java 21
- Spring Boot
- Gradle

## Run
Windows: gradlew.bat bootRun
Linux/macOS: ./gradlew bootRun

## Test
Windows: gradlew.bat test
Linux/macOS: ./gradlew test
